# Healthcare Staffing Platform - Frontend Application

## Connecting Hospitals and Anesthesia Providers — Simply and Securely

At this **Healthcare Staffing Platform**, we’re transforming how anesthesia staffing works. Our mission is simple: **connect hospitals and anesthesia professionals directly** — without agencies, delays, or hidden markups.

We’re building the bridge between **quality care and trusted partnerships**, where every connection is faster, more transparent, and more rewarding for both sides.

---

## 🚀 Tech Stack

This project is built with modern frontend technologies:

- **Framework**: [Next.js](https://nextjs.org/)
- **UI Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) & [Ant Design](https://ant.design/)
- **State Management**: [Redux Toolkit](https://redux-toolkit.js.org/)
- **Form Handling & Validation**: [React Hook Form](https://react-hook-form.com/) & [Zod](https://zod.dev/)
- **Authentication**: [NextAuth.js](https://next-auth.js.org/)
- **Payments**: [Stripe](https://stripe.com/)
- **Video/RTC**: [Agora RTC SDK](https://www.agora.io/en/)
- **Live Chat**: WebSocket API

## 🛠️ Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3007](http://localhost:3007) with your browser to see the result. (Note: The development server is configured to run on port `3007`).

## 📁 Project Structure

- `src/`: Contains the main source code for the application.
- `public/`: Static assets (images, icons, etc.).
- `package.json`: Project dependencies and scripts.
- `next.config.ts`: Next.js configuration.
